# Tech Context

## Technology Stack
- **HTML5**: Semantics and structure.
- **CSS3**: Styling, layouts (Flexbox/Grid), and animations.
- **JavaScript (ES6+)**: Core logic, DOM manipulation.

## Libraries & Dependencies
- **JSZip**: Used for creating ZIP archives (e.g., in C# Class Extractor).
- **FontAwesome**: Iconography.
- **Canvas API**: For graphics and visualization tools.
- **Web Audio API**: For audio tools.

## Development Setup
- No build process required.
- Files served via simple HTTP server or directly from filesystem (though some features like modules might require a server).
- Source control via Git.

## Constraints
- **Client-Side Only**: No backend logic allowed.
- **Browser Compatibility**: Must work in modern browsers (Chrome, Firefox, Edge, Safari).
