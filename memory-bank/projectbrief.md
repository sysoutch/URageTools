# Project Brief

URageTools is a collection of fast, free, and privacy-focused web tools for developers and creators. The project prioritizes client-side execution, ensuring no user data is sent to servers.

## Core Goals
- **Privacy**: All processing happens in the browser.
- **Accessibility**: No registration, free to use.
- **Performance**: Fast, lightweight, no server dependencies.
- **Cross-Platform**: Responsive design for all devices.

## Scope
The project includes tools for:
- Art & Design (Image manipulation, palette extraction, etc.)
- Audio & Sound (SFX generation, visualization)
- Developer Utilities (Code extraction, generators, converters)
- Planning (Kanban, roadmaps, idea generation)
