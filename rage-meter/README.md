# Rage Meter

![Thumbnail](thumbnail.png)

A fun tool to visualize and measure your rage.

## Features
- **Interactive Meter**: Click rapidly to increase the rage level.
- **Visual Feedback**: The meter changes color as rage increases.
- **Cool Down**: The meter slowly drops when inactive.

## Usage
1. Click the button or press spacebar to rage.
2. Watch the meter rise.
3. Try to hit the maximum rage level!
