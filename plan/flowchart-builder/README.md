# Flowchart Builder

Create and export interactive architecture diagrams and flowcharts.

## Features

- Drag components, groups, notes, and labels onto a zoomable canvas.
- Connect nodes, edit the selected item in the inspector, and undo or redo changes.
- Save locally or export the diagram as JSON, SVG, or PNG.
- Request and apply active URage NOW dashboard theme tokens; the toolbar can re-sync them on demand.
